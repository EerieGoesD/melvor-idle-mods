# Melvor Idle Mods

Mods for [Melvor Idle](https://melvoridle.com/) (Steam).

Each mod lives in its own folder with a `manifest.json` at its root, ready to load through the Creator Toolkit in Directory Link mode or to zip and upload to mod.io.

## Mods

| Mod | Description |
| --- | --- |
| [synergy-guard](synergy-guard) | Stops the skill you are training the moment your Summoning synergy ends. |
| [skill-limit](skill-limit) | Set a target number of actions or items on a skill and it stops there. |

## Skill Limit

Adds a bar with an amount field, an Actions/Items switch, an On/Off switch and a live counter. Set an amount, pick a mode, switch it On, start the skill. It stops when the target is reached.

- **Actions** counts times the action is performed. Chop 1000 times. Create Octopus Tablets 1000 times.
- **Items** counts what lands in your bank. 1000 logs. 1000 Octopus Tablets, which is 40 creates at 25 per create.

The bar sits where you start the skill:

| Skill | Bar location |
| --- | --- |
| Woodcutting | one per tree |
| Mining | one per rock |
| Fishing | one per area |
| Thieving | one per area |
| Cooking | one per fire |
| Harvesting | one per vein |
| Archaeology | one per dig site |
| Summoning, Smithing, Fletching, Crafting, Runecrafting, Herblore | above the Create button |
| Firemaking | above the Burn button |

In Woodcutting each tree stops on its own target, so the other trees keep going.

Amount and mode are stored per skill and per character.

Combat, Astrology, Agility and Alt Magic are not affected.

## Synergy Guard

Watches your two summon slots while you train. The moment either tablet stack empties and the synergy stops applying, it stops the skill and shows a message telling you which skill it stopped and why.

Works with any non-combat skill. Combat is left alone.
